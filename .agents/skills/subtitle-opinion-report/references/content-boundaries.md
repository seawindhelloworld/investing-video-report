# 视频原意内容边界

## 正文允许出现

- 视频明确陈述的事实、数字、事件和比较；
- 视频明确表达的因果链、推理过程、预测和判断；
- 视频明确给出的时间范围、对象范围、条件、例外和不确定性；
- 讲者自己的观点，以及讲者明确转述并正确归属给他人、机构或媒体的观点；
- 对上述内容进行不改变原意的压缩、分段、标题化和可视化。

正文采用直接内容语气，不需要每段重复“视频称”或“作者表示”。实际说话人切换或转述观点时必须保留归属。

## 联网边界

网络搜索只对 `analyze` 内的 `understand` 步骤开放，但不是必选项。可按视频内容需要用于：

- 专有名词、机构名、产品名或明显 ASR 歧义的理解；
- 视频所述重要数字的对象、单位或口径消歧；
- 不改变原意的图表、机制图或其他可视化表达；
- 影响文字准确性的必要细节核对。

联网不是外部研究阶段。搜索结果只写入标记为 `internal_only` 的 `understanding-notes.json`，plan 与 draft 不联网。外部信息不得扩展成新的事实层、证据判断、投资建议或 Agent 结论，不得改变视频观点的归属、语气强度、条件或结论，也不得在最终页面加入非视频来源链接。若无法在不扩展原意的前提下使用外部信息，就不写入正文；仍无法确定时保留自然的不确定性。

## 正文不得出现

- 字幕没有表达的事实、因果关系、建议或判断；
- 外部证据研判、Agent 综合判断或个性化交易指令；
- 投资决策总览、证据状态、情景推演、催化剂日历或延伸阅读；
- 非视频来源链接；
- 广告、产品推广、订阅引导、销售话术和无关片尾套话；
- 把转述观点归到讲者本人；
- 声称已经用音视频回听证实字幕。

## 内容筛选与派生视图

- `transcript.corrected.jsonl` 是不可覆盖的上游正文依据。
- 片头/片尾窗口各最多 120 秒，且不得超过字幕总时长的三分之一。只有高确定性的广告、推广、订阅、销售、无关内容或片尾套话可在这些窗口登记到 `excluded_ranges`。
- 中段不得因语义分类从字幕删除。高确定性的中段商业口播登记到 `non_reportable_ranges`，继续保留在 `transcript.corrected.jsonl` 和 `transcript.report.jsonl`，但不得进入观点和最终报告。
- 明显 ASR 噪声可在任何位置按最小连续范围排除；空白段由程序自动清理。
- 不得把相邻区间拆开以规避单段或总占比限制。无法确定时保留。
- `record-meaning-report` 根据分析生成 `content-selection.json` 与 `transcript.report.jsonl`；后者只删除完整的已排除片段，不改写任何保留文字。

## 科技五大新闻

视频确有五条片尾科技新闻时，章节固定命名为“科技五大新闻”。页面不显示该章节的视频时间；定位信息只保留在分析和结构化数据中。若视频并非五条，不得为套模板伪造该板块。

## 报告边界标记

在“视频内容速览”明确显示：

> 报告整理 · 仅据字幕

该标记说明页面是对字幕原意的编辑整理。它不授权加入外部研判，也不声称每个词已经通过回听确认。
