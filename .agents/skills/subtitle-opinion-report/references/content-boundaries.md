# 内容边界

## 正文允许出现

- 视频作者明确表达的观点；
- 对观点的忠实转述；
- 带时间戳的关键原话；
- 视频作者明确给出的依据、限定条件和不确定性；
- 为组织视频内容所需的中性章节标题。

## 第一部分叙事视角

- 在第一部分开头只做一次来源与核查边界声明，此后直接呈现内容本身。
- 不以“视频称”“作者表示”“作者认为”“视频转述”“视频先回顾”等主持式句型反复归因。
- 主观性不能因省略归因而消失：把“作者认为可能上涨”写成“可能上涨”，不能写成“必然上涨”；把“作者倾向于”保留为“倾向于”。
- 当说话人实际切换为公司管理层、嘉宾、投行或其他第三方时，必须保留姓名或身份，例如“管理层预计”“Steven 认为”，避免错误归属。
- 时间戳、直接引语、章节顺序和一次性的部分边界共同承担可追溯性，不需要每句再加主持式前缀。

## 报告编辑层

- 报告自己的核查边界、非投资建议、ASR 风险、删减理由和图表口径不属于原内容。
- 第一部分开头使用视觉隔离块，并明确标记“报告说明（非原内容）”。
- 需要局部说明时，使用独立的“转录提示（非原内容）”；图表解释使用“图表说明（报告整理，非原内容）”。
- 不得把“这是个人投资判断，不构成本报告投资建议”之类的报告提示接在观点正文句尾；观点归属写入报告说明，正文只保留原判断和行动。

## 正文不得出现

- Agent 自己补充的因果关系；
- 外部研究形成的结论；
- 对视频作者动机的推测；
- 把概率判断改写成确定判断；
- 把他人观点错误归给视频作者；
- 无法映射到视频时间戳的内容。
- 外部研判卡片或 Agent 判断卡片；它们只能出现在第二、三部分。
- 没有“非原内容”标识、却由报告加入的免责声明、ASR 提示、删减理由或核查范围说明。
- 商业广告、产品推广、订阅引导、优惠信息或销售话术。它们只在原始转录和分析产物的 `excluded_ranges` 中保留审计位置，不进入 Markdown、HTML、观点或研判。

## 固定科技新闻章节

- 片尾确有五条科技新闻时，固定使用章节名“科技五大新闻”。
- 结构化章节从第一条新闻的时间戳开始，不能把前置广告时段并入。
- 最终 Markdown 和 HTML 不显示本章的视频时间；时间范围只保留在转录、`video-analysis.json` 和 `report-data.json` 中。
- 逐条保留可确认的主题和关键数据限定；密集口播中的不稳定数字按转录提示规则降精度。
- 不使用“片尾五条快讯”“结尾快讯”“产品介绍与五条科技快讯”等名称。

## 外部研判范围

主动研判：

- “我认为”“我预计”“可能会”等主观判断；
- 利好、利空、风险高低和价值评价；
- 未来走势和结果预测；
- 基于某一事实做出的因果推断；
- 投资、政策或行动建议。

默认不主动全面核查：

- 人名、日期、机构名称；
- 一般客观数据；
- 视频转述的公开事件。

不要把“默认不核查”描述为“已经证实准确”。当外部研判自然发现关键前提冲突并且该冲突会改变观点结论时，新增“前提差异”提示。

## 必要声明

每一条外部研判注必须包含：

> 本注为基于外部信源形成的独立研判，不代表视频作者观点。
