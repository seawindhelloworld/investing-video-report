R LOCAL REPORT STUDIO Codex / OpenCode 本机运行

从视频与素材，生成可追溯的深度报告

选择视频报告或素材报告，再指定模型与推理强度。两种模式使用各自独立的内容边界、分析结构和质量验收。

01 / INPUT

导入视频字幕包

标准字幕包 · 最大 100 MB
一个 ZIP 可以包含多份 TXT、Markdown、HTML、DOC/DOCX、RTF 和文字图片；全部素材共同生成一份报告。图片需要选择支持视觉理解的模型。

仅适用于网页服务与字幕文件位于同一台电脑的情况。

02 / MODEL

设置分析参数

执行引擎
OpenCode 将以无人值守模式复用本机权限配置。当前列出的 DeepSeek V4 Flash / Pro 均为文字模型；含图片素材时请改用支持图片的 Codex 模型。

Codex 凭据只保留在运行本页面的电脑上；浏览器不会接触登录信息。
